## 如何重跑與環境限制

在同一基底建立獨立 worktree。重現 red 時，只套用 patch 中的測試檔；重現 green 時，套用整份 patch（以 `git apply --unidiff-zero` 套用這份零上下文補丁）。不要把研究分支當產品分支。

```bash
# 在實驗 worktree；PYTHON 指向 T01 的 .venv/bin/python
PYTHONPATH="$PWD" "$PYTHON" -m pytest -q tests/multimodal/test_utils.py -k preserves_visible_orientation
PYTHONPATH="$PWD" "$PYTHON" -m pytest -q tests/multimodal/test_utils.py tests/multimodal/test_image.py tests/multimodal/media/test_image.py tests/multimodal/media/test_base.py
```

本輪沿用 T01 的虛擬環境，透過 `PYTHONPATH` 載入新 worktree 的 Python 原始碼，並將其 `_C.abi3.so`、`fs_io_C.abi3.so`、`spinloop.abi3.so` 連到 T01 的產物。兩個基底間沒有 native/build 變更；smoke 另以 `inspect.getfile` 確認載入實驗來源。這是純 Python 補丁的局部驗證，**沒有重新 editable install 或完成乾淨建置**；套件 metadata 仍屬 T01，不可拿來標示新的來源版本。其他環境應依官方流程建置對應基底，不直接搬用本機二進位檔。
